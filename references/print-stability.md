# 浏览器打印防翻车排查

用户反馈「打印出来样式不对」「PDF 和屏幕显示不一样」时读这个文件。

## 已预防的坑（base.css 已处理）

### 1. 背景色丢失（双栏侧边栏变白）

**现象**：屏幕预览左栏是深色，打印成 PDF 变成白色。

**原因**：浏览器默认为了省墨，不打印背景色。

**预防**：`base.css` 已加：
```css
* {
  -webkit-print-color-adjust: exact;
  print-color-adjust: exact;
}
```

**如果还是丢**：用户需要在浏览器打印对话框里手动勾选：
- Chrome：展开「更多设置」→ 勾选「背景图形」
- Safari：勾选「打印背景」
- Firefox：勾选「打印背景」

这是浏览器层面的设置，CSS 无法强制覆盖用户的这个选择。

### 2. 经历条目跨页被切断

**现象**：一条工作经历的一半在第 1 页底部，一半在第 2 页顶部。

**预防**：CSS 已加：
```css
.entry, .avoid-break {
  break-inside: avoid;
  page-break-inside: avoid;
}
```

**如果还是切**：
- 内容太多塞不下一页，强制 avoid 也只能切。让用户精简这条经历的 highlights。
- 或者接受切，移除这条 entry 的 `break-inside: avoid`。

### 3. 页边距不对

**预防**：`base.css` 的 `@page`：
```css
@page {
  size: A4;
  margin: 1.5cm 2cm;
}
```

**调整**：用户在打印对话框的「边距」选「默认」或「自定义」。CSS 的 `@page` margin 和对话框设置会叠加，以对话框为准。

## 常见问题排查

### 问题：PDF 里字体变了

**原因**：用户的电脑没装 CSS 指定的字体（如思源黑体），回退到系统默认。

**解决**：
- 中文：确保装了 PingFang SC（macOS 自带）或 Microsoft YaHei（Windows 自带）。base.css 的字体栈已覆盖主流系统字体。
- 如果要确保跨设备一致，需要嵌入 web font（@font-face），但这会让 HTML 文件变大且离线不可用。本 skill 不做嵌入，接受系统字体回退。

### 问题：A4/Letter 切换无效

**检查**：
1. `<html data-page="...">` 是否正确（`a4` 或 `letter`）。
2. 如果用 Letter，`index.html` 的 `<style>` 里是否覆盖了 `@page { size: Letter; }`（base.css 默认是 A4）。
3. 浏览器打印对话框的「纸张大小」是否选了对的（CSS 只是建议，最终以对话框为准）。

### 问题：双栏在第二页错位

**现象**：内容超过一页，第二页的左栏背景没铺满，或左右栏对齐错乱。

**根本原因**：CSS Grid 的多页打印是浏览器已知难题，没有完美方案。

**缓解**：
- 控制简历内容在一页内（A4 单页约 600-800 字 + 列表）。
- 如果必须两页，接受第二页侧栏可能不铺满（背景色不会丢，但可能不到底）。
- 或切换到单栏模板（单栏没有这个问题）。

### 问题：photo 不显示

**检查**：
1. `basics.photo` 路径是否正确（相对 `resume.yaml`，如 `assets/photo.jpg`）。
2. 文件是否真实存在。
3. 英文模板会刻意隐藏 photo（字段白名单规则），不是 bug。

### 问题：打印有页眉页脚（URL、日期）

**原因**：浏览器默认加的。

**解决**：打印对话框里取消勾选「页眉和页脚」（Chrome/Safari 都有这个选项）。

## 终极建议

如果用户怎么调都不对，建议：
1. 换个浏览器试（Chrome 通常最稳）。
2. 截图当前屏幕预览 + 打印预览，对比差异。
3. 精简内容到一页内，规避多页的复杂情况。
