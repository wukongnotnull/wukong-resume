# 简历内容优化指南

这份文档帮助 AI 在收集简历信息时，提供更好的内容建议，让用户的简历更专业、更有竞争力。

---

## 📝 个人简介（Summary）写作建议

### 好的例子：
```
5年前端开发经验，擅长 React、TypeScript、性能优化。曾主导重构电商平台，首屏加载时间从 3.2s 降至 1.1s。热爱开源，GitHub 累计 5k+ stars。
```

### 不好的例子：
```
我是一名前端开发，热爱编程，希望能找到一份好工作。
```

### 优化建议：
1. 开头用年资或经验标签
2. 列出核心技能（2-3个关键词）
3. 加一个核心成就或亮点
4. 控制在 2-4 句话

## 💼 工作经历写法指南

### STAR 法则（但要简短）
- **S**ituation - 背景
- **T**ask - 任务
- **A**ction - 行动
- **R**esult - 结果（最重要！）

### 动词开头 + 量化成果

#### ❌ 不好的写法：
```
- 负责前端开发工作
- 做了很多项目
- 提升了用户体验
```

#### ✅ 好的写法：
```
- 主导电商平台前端重构，首屏加载时间从 3.2s 优化至 1.1s
- 搭建组件库，覆盖 10+ 业务线，提效 40%
- 推动团队规范建设，代码审查覆盖率从 0% 提升至 100%
```

### 常用动词库：
- **技术类**：主导、重构、搭建、优化、开发、实现
- **数据类**：提升、降低、增长、减少、提高
- **团队类**：推动、协调、带领、建立、组织
- **成果类**：完成、交付、上线、获奖、认证

### 量化技巧：
- 用数字：「10+ 业务线」、「5k+ stars」
- 用百分比：「提升 40%」、「降低 65%」
- 用时间：「从 3.2s 降至 1.1s」
- 用金额：「节省成本 ¥50万」

## 🎓 教育背景优化

### 如果是应届生：
- 可以加 GPA（3.5/4.0 以上加）
- 可以加相关课程
- 可以加校园项目

### 如果是工作3年以上：
- 教育背景简化，重点在工作经历
- 除非是名校或相关专业，否则不用太详细

## 🔧 技能展示建议

### 按分类组织：
```yaml
skills:
  - category: 前端技术
    items:
      - React
      - TypeScript
      - Vue 3
      - Webpack
  - category: 后端/工具
    items:
      - Node.js
      - Python
      - Docker
```

### 不要写的技能：
- 太基础：「会用电脑」、「Office」
- 不熟悉：只听过没实际用过的
- 过时的：「jQuery」（除非是维护老项目）

## 📊 简历长度建议

| 工作年限 | 建议页数 | 经历条数 |
|---------|---------|---------|
| 0-3年   | 1页     | 2-3条   |
| 3-5年   | 1页     | 3-4条   |
| 5-10年  | 1-2页   | 4-5条   |
| 10年+   | 2页     | 5-6条   |

### 精简技巧：
- 删除 10 年前的经历（除非特别重要）
- 每条经历的 highlights 控制在 3-5 条
- 用短句，避免长段落

## 🎯 针对不同岗位的风格建议

### 技术岗（程序员、工程师）
- ✅ 推荐风格：`tech`
- ✅ 重点：技术栈、项目、量化成果
- ✅ 建议：加 GitHub、技术博客链接

### 设计岗（UI/UX、平面设计）
- ✅ 推荐风格：`creative`
- ✅ 重点：作品集链接、设计理念、工具
- ✅ 建议：一定要有作品链接

### 管理岗（项目经理、总监）
- ✅ 推荐风格：`business`
- ✅ 重点：团队规模、项目范围、业务结果
- ✅ 建议：突出领导力和影响力

### 金融/咨询岗
- ✅ 推荐风格：`finance`
- ✅ 重点：数据分析、项目金额、客户
- ✅ 建议：强调专业认证

### 学术/研究岗
- ✅ 推荐风格：`academic`
- ✅ 重点：论文、专利、研究方向
- ✅ 建议：加 Google Scholar 链接

### 文字/媒体岗（编辑、记者、文案）
- ✅ 推荐风格：`literary`
- ✅ 重点：作品集、发表作品、阅读量
- ✅ 建议：加作品链接或公众号

## 🚫 简历中不要写的内容

### 绝对不要写：
- ❌ 身份证号（安全红线！）
- ❌ 薪资要求（面试时再谈）
- ❌ 政治倾向（除非岗位需要）
- ❌ 负面信息（为什么离职、被解雇等）

### 谨慎写的：
- ⚠️ 照片（英文简历建议不要）
- ⚠️ 婚姻状况、年龄（英文简历建议不要）
- ⚠️ 太多个人信息

## ✅ 简历检查清单

### 内容方面：
- [ ] 没有拼写错误
- [ ] 时间线连贯，没有重叠或空白
- [ ] 联系方式正确（邮箱、电话、链接）
- [ ] 成果描述都量化了（有数字）
- [ ] 动词开头，不用被动语态

### 格式方面：
- [ ] 字体一致，大小合理
- [ ] 排版清晰，留白适当
- [ ] 项目符号统一
- [ ] 没有奇怪的颜色或格式

### 策略方面：
- [ ] 风格适合目标岗位
- [ ] 重点突出（最近的经历详细写）
- [ ] 删除了无关的经历
- [ ] 有针对性（不是海投简历）
