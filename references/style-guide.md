# 简历风格指南

## 六种预设风格详解

### 1. tech - 技术/程序员风格

**配色方案**：
- 主色调：`#2563eb` (蓝色)
- 次色调：`#dbeafe` (浅蓝)
- 文字色：`#1e293b`
- 辅助色：`#64748b`

**特点**：
- 使用等宽字体增强技术感
- 简洁的区块设计，清晰易读
- 代码风格的项目符号
- 适度的圆角和阴影
- 整体现代、专业

**适用岗位**：
- 前端开发工程师
- 后端开发工程师
- 全栈工程师
- 数据分析师
- 软件架构师
- DevOps 工程师

### 2. creative - 设计/创意风格

**配色方案**：
- 主色调：`#8b5cf6` (紫色)
- 次色调：`#ec4899` (粉色)
- 文字色：`#1f2937`
- 辅助色：`#6b7280`

**特点**：
- 渐变色设计，视觉冲击力强
- 大胆的排版和间距
- 创意的装饰元素
- 圆润的设计语言
- 年轻、活力的感觉

**适用岗位**：
- UI/UX 设计师
- 平面设计师
- 创意总监
- 艺术指导
- 品牌设计师
- 交互设计师

### 3. business - 商务/管理风格

**配色方案**：
- 主色调：`#1e3a5f` (深蓝)
- 次色调：`#d4af37` (金色)
- 文字色：`#111827`
- 辅助色：`#4b5563`

**特点**：
- 传统的排版风格
- 居中对齐的布局
- 正式的字体选择
- 金色点缀增添质感
- 专业、稳重、可信

**适用岗位**：
- 项目经理
- 商务总监
- 企业高管
- 市场营销
- 销售经理
- 人力资源

### 4. finance - 金融/咨询风格

**配色方案**：
- 主色调：`#065f46` (深绿)
- 次色调：`#b8860b` (金色)
- 背景色：`#fefce8` (奶油色)
- 文字色：`#1f2937`

**特点**：
- 精致的细节设计
- 高端的色彩搭配
- 严谨的信息架构
- 金色装饰元素
- 可靠、专业的感觉

**适用岗位**：
- 金融分析师
- 咨询顾问
- 投资经理
- 会计师
- 风控专家
- 基金经理

### 5. academic - 学术/研究风格

**配色方案**：
- 主色调：`#2c5282` (深灰蓝)
- 文字色：`#2d3748`
- 辅助色：`#718096`
- 边框色：`#e2e8f0`

**特点**：
- 简洁的无装饰设计
- 清晰的信息层级
- 学术化的排版
- 保守的配色
- 严谨、可信的印象

**适用岗位**：
- 研究员
- 教师/教授
- 科学工作者
- 博士后
- 图书馆员
- 学术编辑

### 6. literary - 文学/文字工作者风格

**配色方案**：
- 主色调：`#a03428` (砖红色)
- 背景色：`#faf6ed` (米黄色)
- 文字色：`#2c1810` (深棕色)
- 辅助色：`#5c4a3d` (棕灰色)
- 边框色：`#d4c4a8` (米色)

**特点**：
- 温暖的纸张色调，类似书籍排版
- 优雅的衬线字体，良好的阅读体验
- 装饰性的引号和线条元素
- 简洁而有书卷气的设计
- 整体优雅、知性、有文化底蕴

**适用岗位**：
- 作家/小说家
- 编辑/策划编辑
- 记者/特稿作者
- 文案策划/创意文案
- 翻译/译者
- 出版人/版权编辑
- 媒体人/内容运营
- 图书馆馆员/档案员
- 中文系相关岗位

## 如何选择风格

### 考虑因素

1. **行业特性**
   - 互联网/科技 → tech 风格
   - 创意/设计 → creative 风格
   - 传统企业 → business 风格
   - 金融/咨询 → finance 风格
   - 学术/教育 → academic 风格
   - 文字/媒体/出版 → literary 风格

2. **公司文化**
   - 创业公司 → tech 或 creative
   - 成熟企业 → business 或 finance
   - 研究机构 → academic
   - 出版/媒体 → literary

3. **个人偏好**
   - 选择你喜欢的视觉风格
   - 确保风格与你的个性匹配

## 自定义风格

### CSS 变量说明

所有风格都使用 CSS 变量定义，易于自定义：

```css
:root {
  /* 颜色变量 */
  --color-text: #1a1a1a;           /* 主要文字颜色 */
  --color-text-muted: #666;        /* 次要文字颜色 */
  --color-text-light: #999;        /* 辅助文字颜色 */
  --color-border: #e0e0e0;         /* 边框颜色 */
  --color-accent: #2563eb;         /* 主色调 */
  --color-page-bg: #ffffff;        /* 页面背景色 */
  
  /* 字体变量 */
  --font-body: "...";              /* 正文字体 */
  --font-heading: "...";           /* 标题字体 */
  
  /* 字号变量 */
  --fs-name: 2rem;                 /* 姓名字号 */
  --fs-h1: 1.25rem;                /* 标题字号 */
  --fs-h2: 1rem;                   /* 子标题字号 */
  --fs-body: 0.875rem;             /* 正文字号 */
  --fs-small: 0.75rem;             /* 小字字号 */
}
```

### 创建自定义风格

1. 复制一份现有风格的 CSS 文件
2. 修改 CSS 变量的值
3. 调整具体的样式细节
4. 测试在浏览器中的效果

### 字体选择建议

**中文**：
- 系统字体：`PingFang SC`, `Hiragino Sans GB`, `Microsoft YaHei`
- 等宽字体：`SF Mono`, `JetBrains Mono`, `Consolas`
- 衬线字体：`Georgia`, `Times New Roman`

**英文**：
- 无衬线：`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`
- 等宽：`SF Mono`, `JetBrains Mono`
- 衬线：`Georgia`, `Times New Roman`

## 风格切换

在 HTML 文件中，通过引入不同的 CSS 文件来切换风格：

```html
<!-- 必须引入基础样式 -->
<link rel="stylesheet" href="styles/base.css">

<!-- 选择一种风格 -->
<link rel="stylesheet" href="styles/style-tech.css">
<!-- 或 -->
<link rel="stylesheet" href="styles/style-creative.css">
<!-- 或 -->
<link rel="stylesheet" href="styles/style-literary.css">
<!-- 或其他风格 -->
```

## 打印注意事项

1. **背景色**：确保在浏览器打印设置中勾选「背景图形」
2. **边距**：使用标准的打印边距设置
3. **纸张大小**：默认为 A4，可在 CSS 中调整
4. **颜色**：彩色打印效果最佳，黑白打印也能正常显示
