# 表格形式 Word 简历生成规则

生成 docx 阶段（SKILL.md 第四步）读这个文件。

## 核心原则

**表格简历是给国内 HR 看的，清晰易读是第一位。** 用标准的表格布局，中文学术/国企/民企求职常用。

**信息来源**：从第三步已生成的 `index.html`（彩色网页版）中提取内容。

## 从 HTML 提取信息的映射表

| HTML 选择器 | 提取内容 | 表格简历处理 |
|---|---|---|
| `h1.name` | 姓名 | → 填入表格「姓名」/「Name」单元格 |
| `.headline` | 职位定位 | → 填入「应聘职位」/「Position Applied」 |
| `.contact-row .contact-item`（单栏）或 `.contact-list li`（双栏） | 联系方式 | → 分别填入电话、邮箱、地址等对应单元格 |
| `.summary` | 个人简介 | → 填入「自我评价」/「Self Summary」 |
| `.domestic-fields` | 国内字段 | **中文简历**填入性别、民族、政治面貌、籍贯、婚姻、出生年月<br>**英文简历**忽略 |
| `img.photo` | 头像 | → 在「相片」/「Photo」单元格标注「（此处贴照片）」 |
| `h2.section-title` | 板块名 | → 识别为工作经历、教育背景、技能等 |
| `.entry-title` + `.entry-subtitle` | 公司/学校、职位/学位 | → 填入工作经历/教育背景对应行 |
| `.entry-date` / `.entry-meta` | 日期 | → 填入「起止日期」/「Period」单元格 |
| `.highlights li` | 成果 | → 填入「主要职位及职责」/「Position & Responsibilities」或「详细情况」/「Details」 |
| `.skill-category` + `.skill-items` | 技能 | → 整理后填入「计算机水平」/「Tech Skills」和「外语水平」/「Languages」 |
| `.projects` | 项目 | → 可放入「详细情况」或「工作经历」补充 |
| `.awards` | 获奖 | → 放入「个人荣誉」/「Achievements」 |

## pandoc 命令

```bash
pandoc resume.md -o resume.docx \
  --from=gfm \
  --reference-doc=<skill路径>/assets/table-reference.docx
```

- `--from=gfm`：GitHub Flavored Markdown，稳定支持表格语法。
- `--reference-doc`：指向本 skill 的 `assets/table-reference.docx`，定义表格样式。

## pandoc 未装的处理

```bash
which pandoc
```

- 已装（输出路径）→ 跑上面的命令。
- 未装（无输出）→ 告诉用户：
  > 表格 Word 版需要 pandoc。安装方式：
  > - macOS：`brew install pandoc`
  > - Windows：从 https://pandoc.org/installing.html 下载安装包
  > - Linux：`sudo apt install pandoc` 或对应包管理器
  >
  > 不装也能用——PDF 照常打印，只是没有 docx。装好后重新触发本 skill。

  然后跳过 docx 生成，只交付 HTML。
